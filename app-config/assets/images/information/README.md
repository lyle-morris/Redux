# Information Layout Images

Upload transparent PNG previews for the informational slot positions here.

Use these filenames:

- `vertical-slot-1.png`
- `vertical-slot-2.png`
- `vertical-slot-3.png`
- `horizontal-2-slot-1.png`
- `horizontal-2-slot-2.png`
- `horizontal-3-slot-1.png`
- `horizontal-3-slot-2.png`
- `horizontal-3-slot-3.png`

Keep every preview on the same canvas size. The app-config CSS will control
its displayed dimensions.
